Бұл Next.js жобасы болғандықтан, платформа жұмыс істеуі үшін сервер іске қосылуы керек.
Егер бет ашылмаса, терминалда (Command Prompt) осы папканы ашып, npm run dev командасын жазыңыз.

Поскольку это проект на Next.js, для его работы должен быть запущен сервер. Если страница не открывается, откройте терминал в этой папке и запустите npm run dev.
